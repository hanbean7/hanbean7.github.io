Project Overview

This project is a Windows desktop application built with C++ and the Windows API. It simulates a robotic vacuum navigating a furnished home represented as a 14 × 10 grid. Five predefined layouts include walls, furniture, doorways, and accessible floor cells.

The simulator plans a route through all floor cells reachable from the home dock, animates the robot's movement, tracks cleaning progress, and returns the robot to its starting position.

Design & Implementation

Grid-Based Environment

Each cell is classified as free floor, wall, furniture, or outside the room. The five selectable scenarios test navigation through different home layouts and obstacle arrangements.

BFS Pathfinding

Breadth-First Search (BFS) identifies accessible floor cells and computes shortest paths between them. These paths allow the robot to move around known obstacles rather than travelling through walls or furniture.

2-opt Route Optimization

The planner starts with a zigzag route and multiple nearest-neighbour candidate orders, then applies 2-opt to improve the order in which cells are visited. The resulting route begins and ends at the dock.

Windows API Visualization

Windows GDI renders the room, furniture, robot, and cleaning trail. The interface includes a scenario selector, play/pause/replay controls, and a live counter for cleaned cells and movement steps.
